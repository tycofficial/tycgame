让应用随你同行

上传一次，在手机、电脑和学校机房继续使用。

01   上传 HTML 或静态应用

单个 HTML 可直接上传。多文件应用请选择完整文件夹，或多选全部文件，再指定 HTML 入口。手机的文件夹选择取决于浏览器；单 HTML 文件可通过系统文件选择器上传。React、Vue 等项目需先构建，Node、Python、数据库等服务端程序不能直接运行。

02   登录后跨设备访问

应用清单和上传文件保存在云端，与当前账号关联。换设备后使用同一账号登录，便能在主页找到应用。也可以直接输入 本站网址/a/访问后缀/。私有网站的访问者仍需完成登录。

03   分块上传，断点继续

大文件按服务端分片大小上传，可选择 2、4、6 路并发，失败会自动重试。暂停后可继续；关闭页面或换设备后，在应用卡片选择“继续上传”，重新选择原始文件或文件夹，已完成分片会从云端恢复。上传过程中请保持页面打开；手机系统可能暂停后台网页。

04   容量与网络

设计支持 100MB 以上 HTML 和 1GB 静态应用的分块传输。实际容量受云存储配额、服务端设置、浏览器和设备内存限制。并发传输不能绕过配额，也不代表国内专线加速。本站不依赖第三方 CDN 加载界面资源。

05   安全运行与兼容性

上传内容在安全沙箱中运行，以保护你的管理页面。依赖 localStorage、Service Worker、同源身份或特定跨域权限的应用可能受限；部分 ES 模块和联网功能也需要适配。发布器存储文件，不为上传的应用提供专属后端。

06   源码与数据

GitHub 仓库保存发布器源码与部署说明。你上传的 HTML 和应用文件保存在云存储，进入账号应用列表；不会作为大文件提交到源码仓库。删除应用会删除相应云端文件，请自行保留原始文件。
