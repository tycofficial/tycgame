GOOD TO KNOW

你可能还想知道。

让预期清楚，也让创作更自在。

100MB HTML 和 1GB 应用可以上传吗？

发布器按分片保存并支持并发传输，但实际容量受 GitHub 仓库、API 频率、网络、浏览器内存及配额限制。大 HTML 能否流畅运行取决于设备；大项目优先用文件夹上传，避免 ZIP 解压额外占用内存。

为什么需要 GitHub 访问令牌？

GitHub Pages 是静态托管，令牌让浏览器直接向你授权的仓库保存文件。使用细粒度令牌，仅授予目标仓库 Contents 读写权限。令牌只在当前页面内存中使用，刷新或换设备后需重新连接。

本地体验与 GitHub 云端有什么区别？

本地模式使用当前浏览器的 IndexedDB，不跨设备同步。清理网站数据或更换浏览器可能无法再找到文件。GitHub 模式把文件放进仓库数据分支，其他设备连接同一仓库和分支即可访问。

中断后如何继续上传？

在传输中心找到未完成应用，选择继续上传，重新选择同一批原文件。路径和大小需一致，云端已记录的分片会被跳过。手机后台网页可能被系统暂停，上传时请保持页面打开。

所有 Web APP 都可以运行吗？

支持静态 HTML、CSS、JavaScript 及资源。Node、Python、PHP 等服务端程序不能直接运行。请只运行可信应用；应用共享当前站点的浏览器存储。绝对根路径、Service Worker、特定跨域请求可能需要适配。私有仓库运行会话需要保留管理标签页。

内容是否公开？删除是否清除历史？

公开仓库的文件与历史版本可能被任何人读取，请勿上传私密内容。私有仓库读取需令牌。删除会从当前应用库移除数据，但 GitHub 提交历史可能保留先前版本，不等同于安全抹除。

并发等于不限容量、国内专线吗？

并发可以同时传输多个分片，并提供重试与续传；不能绕过配额，也不代表国内专线加速。实际速度由所在地网络、GitHub 可用性和设备决定。
